# Lab 001 — Small Office LAN

## Overview
Built a small office network for the fictional company Summit Solutions using Cisco Packet Tracer. The goal was to connect five workstations and establish reliable local network communication.

## What I Did
- Connected five PCs to a Cisco 2960 switch and Cisco 2911 router.
- Configured static IPv4 addresses on the `192.168.10.0/24` network.
- Set `192.168.10.1` as the default gateway.
- Verified connectivity between workstations and the router using ping tests.
- Labeled and documented the network topology.

## Skills Demonstrated
LAN design · Static IPv4 addressing · Cisco networking · Connectivity testing · Network documentation
