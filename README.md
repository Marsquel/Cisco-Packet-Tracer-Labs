# Cisco-Packet-Tracer-Labs

This repository documents my hands-on experience with network configuration, administration, and troubleshooting using Cisco Packet Tracer.

The purpose of these labs is to develop my networking skills through practical simulations of real-world IT environments.

Each lab includes a Packet Tracer project file, a brief explanation of the work completed, and screenshots verifying functionality.

This portfolio will continue to grow as I explore more advanced networking concepts and enterprise infrastructure.
